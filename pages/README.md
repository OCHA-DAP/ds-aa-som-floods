# The Pages site

This directory is the repo's one GitHub Pages site (team convention: one repo, one
Pages site with a landing page at the root, see `methods/static-data-apps.md` in
`ds-knowledge-base`). `.github/workflows/deploy-pages.yml` publishes `pages/` verbatim as
the site root on every push to `main` that touches it, and again whenever the monitoring
workflow completes; there is no build step. The repo is public, so the site is public at
https://ocha-dap.github.io/ds-aa-som-floods/.

Layout, with the script that writes each directory:

- `index.html`: the landing page, one card per page, hand-edited. Styling is the HDX v2
  tokens plus the particle hero, copied from `ds-seas5-skill`.
- `assets/`: `site.css` (shared tokens) and `hero.js` (decorative particle hero).
- `trigger-single-model/`: the adopted trigger, one model per river-season window.
  `index.html` was generated by `scripts/build_multisource_variant.py` from `trigger/` and
  has since been extended section by section by the generators in
  `scripts/page_additions/` (see its README: skill scores, station metrics, SWALIM
  comparison, model timelines, observational fallback, FloodScan, ensemble agreement).
  `summary.html` is written by `scripts/page_additions/summary_page.py`, which asserts
  its numbers against `index.html` and `src/constants.py`.
- `monitoring/`: the live status page. `index.html` is hand-edited; `status.json` and
  `latest.png` are written by `pipelines/export_monitoring_status.py` in
  `.github/workflows/monitoring.yml`, pushed to the orphan `monitoring-status` branch
  and overlaid here by `deploy-pages.yml`.
- `summary/`: the data-source review (`scripts/build_summary_page.py` with
  `scripts/summary_figures.py`).
- `glofas-version/`: the version 4 / version 5 note (`scripts/build_glofas_version_page.py`).
- `ensemble-agreement/`: the member-agreement sweep. `index.html` is hand-edited; the
  figures and the years table come from `scripts/prob_sweep.py` and
  `scripts/page_additions/ensemble_agreement_figs.py`.
- `activation-timing/`: season charts of the dates the trigger is met
  (`scripts/page_additions/build_timing_page.py`).
- `trigger/`: the multi-source study the adopted design was compared with
  (`scripts/build_multisource_variant.py`; figures under `trigger/figs/`).
- `comparison/`: mixed models against one model per window (`data.json` from
  `scripts/build_comparison_page.py`; `index.html` hand-edited).
- `balanced/`: the balanced multi-model variant (`data.json` from
  `scripts/build_balanced_page.py`; `index.html` hand-edited).
- `explorer/`: the multi-source study's indicator explorer (`data/*.json` from
  `scripts/export_explorer_data.py`; `index.html` hand-edited).
- `temp/`: local previews, ignored by git.

`scripts/check_pages_match_config.py` checks every page's stated rules and return
periods against `src/constants.py`; run it before committing page changes.

## Adding a page

Create a directory under `pages/` with an `index.html`, then add a card to
`pages/index.html`: copy an existing `<a class="k">` block and change the href, title,
blurb and foot.
